# 파티챗

여러 명이 같은 방 비밀번호로 모여 함께 즐기는 AI 롤플레이 채팅입니다. 각자 자기 캐릭터의 행동과 대사를 입력하면, Claude가 모두의 입력을 합쳐서 다음 장면을 이어 씁니다.

## 기능

- **방 입장**: 같은 방 비밀번호를 입력한 사람끼리 한 방에 모입니다. 방 하나에 2~5명까지 들어올 수 있고, 처음 들어온 사람이 방장이 됩니다.
- **방장 설정**
  - 방 제목, 세계관·캐릭터 프롬프트, 오프닝 장면, 기억 메모
  - 모델: Claude Opus 5.5(기본), Sonnet 5.5, Haiku 5.5, Fable 5.2
  - 출력량: 약 400자, 900자, 1800자, 3000자
  - 생각 깊이: 낮음, 보통, 높음
  - 진행 방식: 전원이 제출하면 자동으로 진행하거나, 방장이 ▶ 진행 버튼으로 진행
  - 최대 인원, 기억할 턴 수
- **턴 진행**: 행동은 제출한 뒤에도 수정하거나 취소할 수 있고, 스킵으로 이번 턴을 지켜보기만 할 수도 있습니다. AI가 쓰는 장면은 모두의 화면에 실시간으로 나타납니다.
- **방장 도구**: 다시 쓰기, 되돌리기, 생성 중지, 장면 직접 수정, 강퇴, 방장 넘기기, 처음부터 다시 시작
- **잡담**: AI에게 전달되지 않는 파티원끼리의 채팅입니다.
- **기록**: 이야기를 `.json`(다시 불러오기용)이나 `.txt`로 저장할 수 있습니다. 이야기는 각자의 기기에도 자동으로 백업되어서, 서버가 재시작된 뒤 같은 방에 다시 들어오면 방장이 복원할 수 있습니다.
- **재접속**: 새로고침하거나 연결이 잠깐 끊겨도 3분 안에 다시 들어오면 자리와 방장 권한이 유지됩니다.

## 배포하기 (Render 무료 플랜)

1. [Anthropic Console](https://console.anthropic.com)에서 API 키를 발급하고 크레딧을 충전합니다.
2. [Render](https://render.com)에 GitHub 계정으로 가입합니다.
3. Render 대시보드에서 **New → Blueprint**를 선택하고 이 저장소를 연결합니다. 저장소의 `render.yaml`대로 설정이 자동으로 채워집니다.
4. 환경 변수 두 개를 입력합니다.
   - `ANTHROPIC_API_KEY`: 1번에서 발급한 키 (필수)
   - `ACCESS_PASSWORD`: 서버 입장 비밀번호 (강력 추천). 이 값을 정해 두면 주소를 알아도 비밀번호를 모르는 사람은 들어올 수 없어서, 다른 사람이 내 API 크레딧을 쓰는 걸 막을 수 있습니다.
5. 배포가 끝나면 `https://party-chat-xxxx.onrender.com` 같은 주소가 생깁니다. 친구들에게 이 주소, 입장 비밀번호, 방 비밀번호를 알려 주면 됩니다.

> **무료 플랜 참고**
> - 15분 동안 아무도 접속하지 않으면 서버가 잠들고, 다음 접속 때 깨어나는 데 30초~1분쯤 걸립니다.
> - 서버가 잠들거나 재배포되면 서버 메모리에 있던 방 기록이 사라집니다. 이때는 방장이 같은 방에 다시 들어와 복원 버튼을 누르거나, 저장해 둔 `.json` 파일을 불러오면 됩니다.

## 내 컴퓨터에서 실행하기

Node.js 20 이상이 필요합니다.

```bash
npm install
ANTHROPIC_API_KEY=sk-ant-... npm start   # 실제 AI로 실행
npm run dev                              # 테스트 모드 (AI 호출 없이 가짜 응답)
```

브라우저에서 `http://localhost:3000`을 엽니다.

## 비용

비용은 모델과 이야기 길이에 따라 달라집니다. AI는 매 턴마다 지금까지의 이야기를 다시 읽기 때문에 이야기가 길어질수록 한 턴의 비용도 늘어납니다. 프롬프트 캐싱이 켜져 있어서 반복해서 읽는 부분은 할인된 가격으로 계산됩니다.

비용을 아끼는 방법:

- 모델을 Sonnet 5.5나 Haiku 5.5로 바꿉니다.
- 기억할 턴 수를 줄이고, 중요한 내용은 기억 메모에 적어 둡니다.
- 생각 깊이를 "낮음"으로 둡니다.

## 참고

- 안전 정책 때문에 AI가 장면 생성을 거절하면, Opus, Sonnet, Fable 모델은 서버 쪽에서 자동으로 대체 모델이 이어서 씁니다. 그래도 거절되면 방에 안내 메시지가 뜨고, 제출한 행동은 그대로 남습니다.
- 방 비밀번호가 곧 방 주소입니다. `1234`처럼 흔한 비밀번호를 쓰면 모르는 사람과 같은 방에 들어갈 수 있으니 길고 독특하게 정하세요.
