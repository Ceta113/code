# 파티챗

친구와, 또는 AI 동료와 함께 쓰는 롤플레이 채팅입니다. 각자 자기 캐릭터의 행동과 대사를 내면, Claude가 모두의 행동을 엮어 다음 장면을 이어 씁니다.

## 기능

### 파티 유형
방을 만들 때 고릅니다. 만든 뒤에도 설정에서 인원과 AI 동료를 바꿀 수 있어요.

| 유형 | 구성 |
|---|---|
| 혼자 하기 | 나 + AI 동료 2명 |
| 둘이서 | 사람 2명 + AI 동료 2명 |
| 여럿이서 | 사람 2~5명 |
| 친구 방에 들어가기 | 받은 방 코드로 참가 |

- **AI 동료**는 사람 파티원이 모두 행동을 낸 뒤 차례로 자기 행동을 정하고, 그다음 진행자가 장면을 씁니다. 이름과 성격은 설정에서 바꾸고, 최대 3명까지 둘 수 있어요.
- 방장이 처음 방에 들어오면 예시 세계관 3가지(판타지, 현대 괴담, 무협) 중 하나로 바로 시작할 수 있어요.

### 진행
- 행동과 대사를 따로 낼 수 있어요. 대사로 내면 따옴표가 자동으로 붙어요.
- 낸 뒤에도 고치거나 취소할 수 있고, "이번엔 지켜보기"로 한 턴을 넘길 수 있어요.
- 방장 도구: 기다리지 않고 진행, 다시 쓰기, 되돌리기, 멈추기, 장면 직접 고치기, 방장 넘기기, 내보내기
- 방장 설정: 세계관, 첫 장면, 기억 메모, 모델(Opus 5.5 기본, Sonnet 5.5, Haiku 5.5, Fable 5.2), 장면 길이, 진행자의 고민 정도, 넘어가는 때, 사람 인원, 기억할 분량

### 명령어와 단축어
입력창에 `/`를 치면 명령어 목록이 뜹니다.

| 입력 | 하는 일 |
|---|---|
| `/주사위 2d6`, `/d20` | 주사위를 굴려 결과를 행동에 붙여요. 진행자가 결과로 성패를 정해요 |
| `/지켜보기` | 이번 턴 넘기기 |
| `/대사 할 말` | 대사로 내기 |
| `/잡담 내용`, `//내용` | 진행자 몰래 잡담방에 보내기 |
| `/진행`, `/다시`, `/되돌리기`, `/멈춤` | 방장 진행 도구 |
| `/메모 내용` | 기억 메모에 한 줄 추가 (방장) |
| `/단축어`, `/테마`, `/도움` | 단축어 편집, 밤/낮 바꾸기, 도움말 |

- **내 단축어**: `;관찰` 처럼 `;`와 이름을 적고 띄어쓰면 미리 정해 둔 문장으로 바뀌어요. 입력창 아래 버튼으로도 넣을 수 있고, 각자 기기에 저장돼요.
- **단축키**: `Enter` 내기, `Shift+Enter` 줄바꿈, 빈 입력창에서 `↑` 마지막 행동 불러오기, `Alt+1`/`Alt+2` 행동/대사 전환, `Ctrl+Enter` 바로 진행(방장), `Ctrl+/` 도움말

### 그 밖에
- 잡담방, 밤/낮 테마, 초대 문구 복사
- 이야기를 `.json`(다시 불러오기용)이나 `.txt`로 저장할 수 있어요. 각자 기기에도 자동으로 백업되어서, 서버가 다시 켜진 뒤 같은 방 코드로 들어오면 방장이 이어서 할 수 있어요.
- 새로고침하거나 연결이 잠깐 끊겨도 3분 안에 돌아오면 자리와 방장 권한이 유지돼요.

## 배포하기 (Render 무료 플랜)

1. [Anthropic Console](https://console.anthropic.com)에서 API 키를 발급하고 크레딧을 충전합니다.
2. [Render](https://render.com)에 GitHub 계정으로 가입합니다.
3. Render 대시보드에서 **New → Blueprint**를 선택하고 이 저장소를 연결합니다. 저장소의 `render.yaml`대로 설정이 자동으로 채워집니다.
4. 환경 변수 두 개를 입력합니다.
   - `ANTHROPIC_API_KEY`: 1번에서 발급한 키 (필수)
   - `ACCESS_PASSWORD`: 서버 입장 비밀번호 (강력 추천). 이 값을 정해 두면 주소를 알아도 비밀번호를 모르는 사람은 들어올 수 없어서, 다른 사람이 내 API 크레딧을 쓰는 걸 막을 수 있습니다.
5. 배포가 끝나면 `https://party-chat-xxxx.onrender.com` 같은 주소가 생깁니다. 방에 들어가서 "초대 문구 복사"를 누르면 주소와 방 코드가 담긴 문구가 복사돼요. 입장 비밀번호는 따로 알려 주세요.

> **무료 플랜 참고**
> - 15분 동안 아무도 접속하지 않으면 서버가 잠들고, 다음 접속 때 깨어나는 데 30초~1분쯤 걸립니다.
> - 서버가 잠들거나 재배포되면 서버 메모리에 있던 방 기록이 사라집니다. 이때는 방장이 같은 방에 다시 들어와 복원 버튼을 누르거나, 저장해 둔 `.json` 파일을 불러오면 됩니다.

## 내 컴퓨터에서 실행하기

Node.js 20 이상이 필요합니다.

```bash
npm install
ANTHROPIC_API_KEY=sk-ant-... npm start   # 실제 AI로 실행
npm run dev                              # 테스트 모드 (AI 호출 없이 가짜 응답)
```

브라우저에서 `http://localhost:3000`을 엽니다.

## 비용

비용은 모델과 이야기 길이에 따라 달라집니다. AI는 매 턴마다 지금까지의 이야기를 다시 읽기 때문에 이야기가 길어질수록 한 턴의 비용도 늘어납니다. 프롬프트 캐싱이 켜져 있어서 반복해서 읽는 부분은 할인된 가격으로 계산됩니다.

비용을 아끼는 방법:

- 모델을 Sonnet 5.5나 Haiku 5.5로 바꿉니다.
- AI 동료 수를 줄입니다.
- 기억할 턴 수를 줄이고, 중요한 내용은 기억 메모에 적어 둡니다.
- 진행자의 고민 정도를 "가볍게"로 둡니다.

## 참고

- 안전 정책 때문에 AI가 장면 생성을 거절하면, Opus, Sonnet, Fable 모델은 서버 쪽에서 자동으로 대체 모델이 이어서 씁니다. 그래도 거절되면 방에 안내 메시지가 뜨고, 제출한 행동은 그대로 남습니다.
- 방 코드가 곧 방 주소입니다. `1234`처럼 흔한 코드를 쓰면 모르는 사람과 같은 방에 들어갈 수 있으니, 자동으로 만들어 주는 코드를 쓰는 걸 추천해요.
- AI 동료가 있으면 턴마다 동료 수만큼 짧은 AI 호출이 더 생겨요. 비용을 줄이려면 동료 수를 줄이세요.
